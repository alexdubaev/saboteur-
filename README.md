# Золото и предатели

Самостоятельная многопользовательская браузерная карточная игра. В закрытой альфе 3–10 участников получают тайные роли, прокладывают туннели и ищут две золотые жилы. Доступен экспериментальный профиль «Две жилы» v0.

## Запуск

Нужны Node.js 24.15.0 или новее в ветке 24, pnpm 11.25.0 и Docker Compose. Скопируйте `.env.example` в `.env`, назначьте локальный пароль PostgreSQL и заполните `DATABASE_URL` адресом из [инструкции запуска](docs/ALPHA_RUNBOOK.md).

```sh
pnpm install --frozen-lockfile
docker compose up -d --wait db
pnpm migrate
pnpm dev:server
```

В другом терминале запустите `pnpm dev` и откройте [localhost:4173](http://127.0.0.1:4173). Ведущий создаёт комнату и отправляет код или ссылку участникам. Для отдельного локального прогона `PLAYTEST_MODE=1` разрешает ведущему добавить обозначенных ботов.

# Золото и предатели

Коммерческий проект многопользовательской браузерной карточной игры: скрытые роли, прокладка туннелей, поломки, ремонт, разведка, обвалы и поиск золота.

## Статус — 9 ноября 2026

**Технический ассет-пак для разработки и тестов опубликован. Код самой игры ещё не создан.** Подготовлены 35 уникальных карточных иллюстраций / 70 WebP в разрешениях 512×768 и 256×384, 22 SVG-иконки, 2 фона, элементы дизайна, логотип, иконка приложения, мобильные референсы и документация. Поставка включает 101 проверенный ресурс в [манифесте](data/asset-manifest.json).

Вся общая колода имеет единый размер и **не содержит текста на лицевых сторонах**. Туннельные выходы открыты до границы карточки. Программная логика соединений находится в `data/cards.json`, а не выводится из картинки.

**Не считать готовой коммерческой игрой:** игровые тесты, визуальная приёмка, автономная логика, мультиплеер и юридическая проверка ещё впереди. Для ряда изображений, созданных на общих листах, рекомендуется отдельная художественная доработка перед коммерческим запуском.

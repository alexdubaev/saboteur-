# Золото и предатели

Самостоятельная многопользовательская браузерная карточная игра: скрытые роли, соединяемые туннели, препятствия, ремонт, разведка, обвалы и поиск золота. Первая цель — закрытая альфа на телефоне и компьютере без мессенджеров.

## Начало разработки
1. [AGENTS.md](AGENTS.md) и [полное ТЗ 2.0](docs/FULL_TECHNICAL_SPEC.md).
2. [Вопросы правил](docs/RULES_DECISIONS.md) и [статус](docs/STATUS.md).
3. [Каталог v2](data/card-catalog-v2.json), [конфигурация](data/game-config.json), [предложенный тестовый профиль «Две жилы»](data/rulesets/playtest-expedition-v0.json).
4. Реально существующие ресурсы — data/asset-manifest.json и последняя локальная поставка владельца. Исторический data/cards.json не определяет активную колоду.

ТЗ v2.0 заменяет прежнюю задачу точного воспроизведения конкретного коммерческого издания. Реализуем универсальный движок, сетевую инфраструктуру и UI; тестовый профиль самостоятельный, не утверждён для выпуска. Коммерческие правила и права согласуются отдельно.

В этом репозитории пока ранний набор ассетов; последняя локальная поставка содержит новые растровые карты и иконки. Не использовать SVG, не считать отсутствующий файл опубликованным, не заменять графику скриншотами или заглушками в финальной версии. Не подключать Base44, fal и платные сервисы без разрешения. Telegram/MAX/VK — после тестирования браузерной игры.

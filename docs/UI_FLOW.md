# UI/UX — браузерный прототип

1. Главное меню: новая комната, присоединиться, правила.
2. Лобби: код и ссылка, участники, готовность, настройки, старт.
3. Приватная роль: только собственная роль; подтверждение.
4. Игра: компактная верхняя строка, аватары/неисправности, прокручиваемое поле, рука снизу, подтверждение хода, чат/журнал.
5. Выбор действия: игрок, тайл или цель, согласно типу карты.
6. Разведка: приватный результат, без общего уведомления о содержимом.
7. Конец раунда: роли, найденная цель, награды.
8. Итоги матча: личные очки, победители, повторить.
9. Переподключение: сохранённая комната, актуальная ревизия, без утечки секретов.

### Телефон
Минимальный тест 360×800 CSS px; поле pinch-to-zoom, панорамирование, доступные клетки подсвечиваются отдельно. В руке карточки одинаковой пропорции, выбор и подтверждение не должны перекрывать поле.

### Компьютер
Широкая область шахты, боковая панель участников и чата. Используется тот же игровой движок.

### Изображения
`docs/previews/*.webp` — только референсы. Не использовать целые макеты как кликабельные экраны. Кнопки, текст, состояния, сетка, выделение и таймер должны быть настоящими UI-компонентами.

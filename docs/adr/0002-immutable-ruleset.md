# ADR 0002. Версия правил закрепляется за матчем

Статус — принято для закрытой альфы по ТЗ 2.0.

## Контекст

«Две жилы» использует версии каталога и профиля правил. Матч должен продолжаться с теми же правилами после перезапуска, а альтернативный профиль должен проверяться через тот же движок.

## Решение

При создании матча движок проверяет каталог и JSON-профиль. Снимок матча сохраняет неизменяемое определение правил, включая ID, версию и SHA-256 канонической сериализации профиля. Версия схемы снимка ведётся отдельно от версии правил.

Каталог задаёт типы карт и соединения портов. Профиль задаёт состав колоды и параметры матча. Исполняемое поведение выбирается из известных функций движка. Например, для «Двух жил» функция исхода проверяет одновременную достижимость обеих жил по компонентам связности.

## Альтернативы и последствия

Правила, зашитые в движок целиком, потребовали бы изменения кода для каждого варианта состава колоды. Подстановка текущего профиля при восстановлении могла бы изменить правила уже начатой партии. Закреплённое определение позволяет проверять другой профиль тем же движком и восстанавливать матч по исходной версии. Новая исполняемая стратегия требует изменения движка.

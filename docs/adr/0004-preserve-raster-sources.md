# ADR 0004. Исходники арта и растровая сборка поля

Статус — принято для закрытой альфы по ТЗ 2.0.

## Контекст

Локальная поставка владельца содержит исходники и новый набор игровых растров. Совпадающие карточные пути в старой и новой поставках по результатам сверки имели разные SHA-256. Геометрия входа и раскрытой камеры должна соответствовать портам активного профиля.

## Решение

ZIP и исходные JPG владельца сохраняются с проверкой исходных SHA-256. Из новой поставки берутся проверенные игровые WebP и метаданные. Подготовленные для поля изображения сохраняют существующий рисунок и отражают порты профиля. Для «Двух жил» вход имеет четыре связанных порта, раскрытая камера — один западный порт W.

Интерфейс разрешает `assetId` через манифест. Сборка Vite включает растровые файлы из списка допуска, соответствующего манифесту. Проверенный PNG допускается, если он требуется ТЗ. SVG, архивы, исходные PNG, макеты и старый набор остаются за пределами сборки.

## Альтернативы и последствия

Выбор файлов по совпадению имён смешал бы версии арта. Публикация всего каталога графики добавила бы в сборку рабочие материалы и старые файлы. Цельный набор с явным списком допуска сохраняет происхождение изображений и позволяет проверять отдельно геометрию игрового поля и состав сборки.

# ADR 0001. Архитектура закрытой альфы

Статус — принято для разработки по ТЗ 2.0 от 27 ноября 2026 года.

## Контекст

«Золото и предатели» должна запускаться на телефонах и ПК через один сервер. Сервер хранит полное состояние и отправляет отдельную безопасную проекцию каждому игроку. Матч воспроизводим в тестах, использует закреплённый профиль и восстанавливается после перезапуска.

## Решение

- Node.js 24 LTS, TypeScript и закреплённые зависимости через pnpm. Чистые функции движка и версия конфигурации позволяют тестировать игровую логику вне UI и сети.
- React и Vite используют DOM/CSS и существующие изображения WebP. Публичные картинки попадают в сборку по манифесту. В ходе разработки Vite проксирует HTTP и WS к тому же API.
- Hono и WebSocket предоставляют вход гостем, комнаты, живые персональные проекции, переподключение и журнал. Доступ проверяется сервером на каждом входе в комнату.
- PostgreSQL хранит сессии, комнаты, снимки, события и квитанции. Блокировка строки комнаты сериализует изменение снимка и запись квитанции. Зависимости, миграции и тестовая БД воспроизводимы локально.
- Vitest проверяет правила и интеграцию с PostgreSQL. Playwright запускает независимые браузерные контексты и проверяет критический сценарий игры.
- Локальная поставка хранит исходники арта. Web использует проверенную растровую библиотеку исходного авторства, включая две размерности карт. Недостающие или непрошедшие художественный контроль материалы фиксируются в аудите.

## Последствия

Разворачивается один сервис приложения и одна БД. Отказ сети восстанавливается полным персональным снимком. Закрытая альфа использует профиль «Две жилы» с внутренней пометкой; решение по окончательным правилам остаётся отдельным.

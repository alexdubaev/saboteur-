# Codex — начинаем разработку браузерной игры

Передано: 33 уникальных карты (11 туннелей, 11 действий, 5 целей/старт, 2 роли, 3 награды и рубашка), 2 размера всех карт, художественные UI-ресурсы, SVG-значки, фоновые изображения, бренд, манифест и правила. Макеты находятся в docs/previews и не являются приложением.

## Порядок

1. Прочитать AGENTS.md, docs/ASSET_SPEC.md, docs/GAME_RULES_V1.md, docs/GAME_LOGIC_SPEC.md и data/cards.json.
2. Реализовать чистый типизированный игровой движок на TypeScript с тестами; поле по графу внутренних соединений, секреты только на сервере.
3. Поднять комнаты по ссылке и адаптивный браузерный интерфейс без Telegram/MAX/VK SDK.
4. Реализовать приватную раздачу роли, 3 раунда, действия, личный счёт, чат/журнал, переподключение, защиту от повторных ходов.
5. Провести тесты на телефон/компьютер с несколькими реальными браузерами.
6. После приёмки обсуждать платформенные адаптеры и коммерческий релиз.

Не импортировать Vibe целиком. Не включать Base44, fal, платные сервисы и сторонние генераторы без явного согласования. Отчёт отделяет автоматически проверенное от непроверенного художественного качества.

# Производственный план — Золото и предатели

> Для агентов-исполнителей: выполнять задачи последовательно, проверяя каждый результат; для программной реализации использовать superpowers:executing-plans либо эквивалентный проверяемый процесс. Не считать список задач отчётом о выполнении.

**Goal:** рабочий художественный ассет-пак, затем точные правила и тестируемая браузерная игра.
**Architecture:** точная геометрия и состояние задаются данными; рисованные материалы задают художественный вид; интерфейс собирается из компонентов. Правила не зависят от будущих платформенных адаптеров.
**Tech Stack:** на текущем этапе Markdown/JSON и художественные файлы; стек самой игры ещё не утверждён. Не импортировать Vibe целиком по умолчанию.
**Spec:** ASSET_SPEC.md, ART_DIRECTION.md, ASSET_CATALOG.md.

## Глобальные ограничения

- Одинаковый размер всех карт общей колоды: рабочий экспорт 512 × 768, соотношение 2:3.
- Нет встроенного текста на туннелях и действиях.
- Карты стыкуются без рамок/подписей поперёк проходов.
- Яркий насыщенный рисованный стиль, утверждённый пользователем.
- Сначала браузер для телефона и компьютера; интеграции Telegram/MAX/VK после тестов.
- Публикация рабочих материалов в alexdubaev/saboteur-.
- Нельзя утверждать готовность отсутствующих файлов или завершённость невыполненных тестов.

## Фокус проверки

1. Перекрёсток должен соединяться со всеми четырьмя соседями, а его поворот не создавать шов.
2. Раздельные тупики не соединяются игровым движком, даже если у них два открытых края.
3. Поломку и ремонт можно отличить в руке на узком телефоне без текста.
4. Приватная информация не попадает в публичные UI/сеть/аватары/журнал.
5. Макет, плановый путь и будущий бюджет веса не выдаются за работающий ассет, файл или измерение.

## Этап D. Проверка продукта

Минимальная матрица экранов: 360 × 800, 390 × 844, 768 × 1024, 1440 × 900 CSS px. Это тестовые размеры, не список гарантированно поддержанных устройств.

Проверки: реальные партии; 3 и 10 участников; конец колоды; обвал с отрезанной веткой; восстановление соединения; несколько поломок; повтор отправки команды; разрыв связи после подтверждения; отсутствие утечки роли; чат с длинным сообщением; крупный текст; выключенная анимация; загрузка на слабом соединении.

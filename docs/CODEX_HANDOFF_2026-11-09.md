## Технический порядок для Codex
1. Импортировать архив, не перезаписывая более новые файлы без сравнения.
2. Использовать `data/cards.json` как источник количества карт и связности. Считать числа прототипными.
3. Реализовать чистый движок, покрыть тестами размещение, поворот, отрезанные ветки, поломки, ремонт, разведку, завершение.
4. Реализовать сервер комнат и приватные представления состояния. Никаких секретных ролей или карт чужим клиентам.
5. Реализовать адаптивный браузерный интерфейс для телефона и ПК. Использовать картинки только как отдельные компоненты; не использовать целый мокап как экран.
6. Тестировать, после этого обсуждать интеграции Telegram/MAX/VK.
7. Разработка через Codex. Base44/fal и платные внешние генерации без согласования не использовать.

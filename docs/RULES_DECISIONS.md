# Решения по правилам — отдельный gate коммерческой версии

ТЗ 2.0 разрешает разработку универсального движка и закрытое тестирование `playtest-expedition-v0`. Оно не устанавливает финальные правила коммерческой игры.

| Вопрос | Предложение для внутренней альфы | Статус |
|---|---|---|
| Победа | Две жилы одновременно связаны со входом | Предложено, не утверждено |
| Камеры | Три позиции, две жилы и пустая, фиксированный W; не транзит | Предложено |
| Колода | 40 туннелей + 26 действий, 66 экземпляров, новые количества | Предложено, симуляция необходима |
| Роли | 1/2/3 предателя по размерам, гарантированы | Предложено |
| Раунды/рука | 3 раунда, 5 или 4 карты | Предложено |
| Время | 6×N+6 ходов на раунд | Предложено |
| Награды | Числовое начисление, без драфта, бонус завершающему старателю | Предложено |
| Сюжет и арт | «Золото и предатели», утверждённая яркая рисованная шахта | Сохранить |
| Платформы | Браузер сначала | Утверждено |

Владелец принимает/корректирует предложения после демонстрации и симуляций. Не считать согласование разработки универсального движка согласием на эти числа как коммерческие правила. Новое решение фиксировать отдельной версией ruleset и тестами. Не восстанавливать полное чужое издание под переименованным профилем. Если нужна лицензированная адаптация, сначала отдельное подтверждение разрешения и условий. Перед публичным выпуском — правовая проверка.

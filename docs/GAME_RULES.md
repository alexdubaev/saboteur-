# Правила текущего тестового профиля

Актуальный источник: [полное ТЗ 2.0](FULL_TECHNICAL_SPEC.md), разделы 2–3, и `data/rulesets/playtest-expedition-v0.json`. Это самостоятельный предложенный режим «Две жилы» для закрытого тестирования: 3–10 игроков, 3 раунда; 2 золотые камеры и 1 пустая; победа бригады — одновременная доступность обеих жил, предателей — исчерпание ходов или карт. Каждая камера принимает только W и не является транзитной. Состав 66 экземпляров; 40 туннелей + 26 действий. Роли и размер рук задаются профилем. Одна карта за ход: строительство, действие, сброс; добор после нетерминального хода. Поломка блокирует строительство; ремонт снимает одну, разведка приватна, обвал удаляет обычный тайл. Награды — личный числовой счёт по формулам v0, без драфта. Коммерческие правила не утверждены, не менять их самостоятельно и не возвращать прежний набор.

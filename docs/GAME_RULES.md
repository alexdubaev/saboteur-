# Правила текущего тестового профиля

В «Пути к золоту» играют 3–10 участников. Матч длится три раунда. Сервер перемешивает три закрытые камеры, среди которых одна золотая. До центральной камеры семь свободных клеток от входа. Каждая камера имеет западный вход. Открытая пустая камера остаётся на поле.

В начале раунда игроки получают тайные роли. При 3–4 участниках с вероятностью 20% все становятся старателями, иначе назначается один предатель. При 5 участниках есть один предатель, при 6–8 два, при 9–10 три. Первый стартующий выбирается случайно. В следующем раунде начинает следующее место после прошлого стартующего.

В колоде 40 туннелей и 27 действий. Стартовая рука состоит из 6 карт при 3–5 участниках, из 5 при 6–7 и из 4 при 8–10. В ход игрок кладёт туннель, играет действие или сбрасывает карту в закрытую. Затем он добирает одну карту, если раунд продолжается и в колоде есть карты. Поломка мешает строить, ремонт снимает одну поломку, обвал убирает обычный туннель, разведка показывает одну камеру только игроку.

Когда вход соединён с золотом, старатели получают по 2 очка. Старатель, который завершил путь, получает ещё 1. Когда колода и руки пусты, а золото не найдено, предатели получают по 2 очка. Если предателя не было, все получают 0. После трёх раундов выигрывают участники с наибольшей положительной суммой. Если у всех ноль, матч заканчивается без победителя.

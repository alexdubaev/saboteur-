# Графика закрытой альфы

## Поставка

В альфу перенесены 107 WebP из `gold-traitors-project-with-tz.zip` и реестр [asset-manifest.json](../data/asset-manifest.json) версии 3. 40 карточных рисунков поставлены в двух размерах, 512×768 и 256×384. Остальные файлы включают 24 растровые иконки, логотип и два кандидатных фона. Все WebP занимают 6 599 840 байт. Для карточек реестр хранит ID, оба пути, размеры, байты, SHA-256, статус QA, путь и SHA-256 исходного PNG. Исходники находятся в `gold-traitors-project/art-source/` внутри ZIP. Исходники фонов и логотипа лежат в одноимённых каталогах, иконки подготовлены из `art-source/ui/icon-atlas.png`. Активный каталог и тестовый профиль берутся из этой ветки.

| Локальный документ | SHA-256 |
| --- | --- |
| `gold-traitors-project-with-tz.zip` | `54394244e624ea6a4087822e8fddce08e846ed5373546143d8278ee62273e16e` |
| `gold-traitors-tunnels-16-preview.jpg` | `a3f4601d586e022499f8a428d74e10262d1ac720ecdac1860a4a7c6bd9e48f00` |
| `gold-traitors-project/data/asset-manifest.json` внутри ZIP | `06da0822104bdad349e9751627981b65ec02502091e1dd43c19663dc85170fd0` |

SHA-256 владельческих ZIP и JPG сверены до и после импортирования. JPG побайтно совпадает с `docs/previews/tunnels-16.jpg` в ZIP. Все 40 исходных PNG в ZIP проверены по хешам и размеру 1024×1536. Для WebP сохраняются исходные байты, в том числе у `role-prospector.webp` размером 126 786 Б. Это единственное превышение целевых 120 КиБ для стандартной и 45 КиБ для компактной карточки. Исторический проверщик `tools/verify_assets.py` и отчёт `data/asset-verification.json` относятся к прежнему набору. Активную поставку проверяет `tools/verify_assets_v2.py`.

## Вход и камеры на игровом поле

В [board-art-v2.json](../data/board-art-v2.json) описан отдельный технический экспорт `board-start`, `goal-gold`, `goal-empty-a` и `goal-empty-b` из новых черновиков ImageGen. Манифест хранит их исходные пути, SHA-256 и варианты WebP. PNG 1024×1536 сохранены рядом с рабочей копией в `../board-art-v2-candidates/`. Оригинальные 107 WebP и их реестр сохранены. На поле открываются четыре связанных порта входа и единственный W-порт каждой раскрытой камеры. У закрытых целей общая карта `goal-hidden` из поставки владельца.

```sh
python tools/prepare_board_art_v2.py ../board-art-v2-candidates
```

Экспорт воспроизведён с Pillow 12.2.0 и libwebp 1.6.0. Скрипт масштабирует рисунки до размеров ТЗ, совмещает кромки с `tunnel-cross` для входа и `tunnel-dead-end-e` с поворотом 180° для камер. Переход к исходному рисунку плавный в пределах 56 px у стандартной карты и 28 px у компактной. Восемь вариантов укладываются в целевые 120/45 КиБ. На контрольных парах кромки сходятся с обычным туннелем. У камер различимы самородки, пустая выработка и глухая каменная стена.

## Результат QA

Команды из корня репозитория требуют Python 3.10+ и Pillow с поддержкой WebP.

```sh
python tools/verify_assets_v2.py package
python tools/verify_assets_v2.py package --owner-zip ../gold-traitors-project-with-tz.zip --owner-preview ../gold-traitors-tunnels-16-preview.jpg
python tools/verify_assets_v2.py tunnels
python tools/verify_assets_v2.py board --source-dir ../board-art-v2-candidates
python tools/verify_assets_v2.py dist --dist apps/web/dist
```

| Проверка | Результат |
| --- | --- |
| A01 · `package` с ZIP и JPG | Код 0. Декодированы 107 WebP, проверены размеры, байты, хеши, содержимое поставки и пути активных карт. |
| A01 · `dist` | Проверяется на сборке E5. Каждый из 115 WebP (107 из ZIP и 8 экспортов для поля) должен присутствовать с правильным хешем. Исторические PNG, WebP, SVG, архивы и исходники за пределами списка запрещены в сборке. |
| A02 · `tunnels` | Код 0. По 128 проверок кромок и 1 060 допустимых стыков на размер для 16 туннелей с поворотами 0° и 180°. Входы шириной 158–160 / 78–80 px. Связность рисунков совпала с компонентами каталога, включая раздельные тупики. |
| A02 · `board` | Код 0. Проверены четыре источника PNG, восемь экспортов и по 16 кромок в каждом разрешении. Все четыре порта входа образуют общий компонент, у каждой открытой камеры только западный порт. |
| A02 · браузер | Сборка реального поля при DPR 1/2/3 и художественная приёмка остаются открытыми. |

Проверщик туннелей использует цветовой порог из QA владельца и сравнивает связанные участки рисунков с метаданными v2. Максимальная средняя разница RGB на открытом стыке составила 2,421 для стандартных и 3,492 для компактных. Геометрия игровой логики определяется тестовым профилем и каталогом.

## Открытый E4

- Четыре технических экспорта для поля имеют статус `art-review-required`. У исходных карт владельца рамка остаётся частью рисунка. При первой проверке их кромок зафиксировано 35 расхождений. У новых черновиков перед совмещением кромок выявлено семь неверных полос в каждом разрешении.
- В трёх картах двойного ремонта видны оба инструмента. Сам рисунок допускает трактовку «ремонт обоих», поэтому выбор одного должен явно читаться в управлении. У карты поломки фонаря видны разбитое стекло и дым, но сохранилось янтарное свечение. Художественная приёмка этой карты открыта. Награды 1/2/3 различимы по числу крупных самородков на просмотренных компактных рисунках.
- 16 иллюстраций имеют статус `geometry-verified`, 4 — `board-geometry-unverified`, 20 — `art-review-required`. Оба фона (`mine-scene-corridor` и `mine-scene-junction`) остаются кандидатами.
- В актуальной поставке отсутствуют 4–10 утверждённых нейтральных аватаров, `app-icon-192.png`, `app-icon-512.png`, `social-cover.webp` и материалы интерфейсных панелей. Одноимённые файлы прежней поставки лежат вне реестра альфы.

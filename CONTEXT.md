# Термины «Золота и предателей»

| Термин | Значение |
| --- | --- |
| Комната | Закрытое пространство с лобби, местами и текущим матчем. После итогов в той же комнате можно начать новый матч. |
| Место | Позиция игрока или бота в комнате. Временный разрыв соединения во время матча сохраняет место. |
| Матч и раунд | Матч по профилю «Две жилы» состоит из трёх раундов. Роли раздаются заново каждый раунд, личные начисления складываются в итоговый счёт. |
| Профиль правил | Версионированные параметры матча, включая состав колоды. «Две жилы» соответствует профилю `playtest-expedition-v0`. |
| Тип и экземпляр карты | Тип описан в каталоге. Экземпляр — отдельная копия типа в матче со своим ID. |
| Порт и компонент связности | Порт — выход на сторону карты. У одной карты может быть несколько изолированных компонент, поэтому путь между двумя портами определяется соединениями внутри карты. |
| Камера и жила | Камера — одна из трёх скрытых целей с публичным западным портом. Две жилы должны быть одновременно достижимы от входа для победы старателей в раунде. |
| Разведка | Игровое действие, которое показывает содержимое выбранной камеры только игроку, выполнившему разведку. |
| Игровая ревизия и снимок игрока | Ревизия — номер принятого изменения матча. Снимок игрока показывает состояние на этой ревизии в пределах прав его места. |

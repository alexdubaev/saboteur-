## Что должно заработать

На телефоне и ПК работают приглашение, роль, шахта, рука, действия, чат и итоги.

## Из брифа

> Приступай к разработке согласно новому техническому заданию.

## Критерии приёмки

- [ ] React UI использует настоящий API и WebSocket, показывает статусы и приватные данные, выполняет ход через явное подтверждение.
- [ ] Мышь, клавиатура и тач, портрет и ландшафт; существующий рисованный арт и текущий манифест.
- [ ] Playwright покрывает независимые контексты, комнату, повторное подключение и шахту. Интегральный полный матч проверяется при готовности сервера.
- [ ] Production web dist не содержит SVG, архивов, исходников и макетов.

## Что должно заработать

Участники входят по приглашению, играют через общий сервер и возвращаются на то же место.

## Из брифа

> Приступай к разработке согласно новому техническому заданию.

## Критерии приёмки

- [ ] Начальный и повторный матч приходят из PostgreSQL, события и квитанции атомарны; HTTP и WS идут через единый путь.
- [ ] N01–N07 на отдельной БД покрывают membership, гонки, идемпотентность, проекции, reconnect и restart.
- [ ] Боты и таймер используют тот же reducer, чат и presence отделены от игровой ревизии.
- [ ] API и команды совместимы с interfaces.md. Проверки core доступны к интеграции, код сервера готовится параллельно.

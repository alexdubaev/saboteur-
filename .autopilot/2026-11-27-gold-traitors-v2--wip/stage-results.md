# Результаты проверки по этапам

Рабочая ветка codex/alpha-v2 от a24dcf8. Актуальное ТЗ — 2.0. Ниже перечислены выполненные прогоны.

## E0. Аудит и основа

Коммит 7ddcdde. Локальная main обновлена до a24dcf8. Проверены действующие ссылки, 16 геометрий, 11 действий, 40 + 26 экземпляров. Аудит растровых путей записан в notes.md, решение о стеке в docs/adr/0001-alpha-architecture.md.

- В чистой копии установка по lockfile и pnpm check прошли. Vitest 1/1.
- Два отрицательных прогона отвергли выбор data/cards.json и неверное количество туннелей.
- pnpm audit --audit-level high прошёл. Исторический тест импорта 1 прошёл и 1 пропущен без старой fixture, в приёмку v2 не засчитывался.

## E1. Движок

Коммит faa35e7. pnpm exec vitest run tests/core — 16/16. ESLint для packages/game-core, packages/config и tests/core прошёл.

Команда pnpm simulate --matches-per-size 100 --seed 20261127 завершила 800 матчей и 2 400 раундов без нарушений инвариантов за 29 031 мс. SHA-256 профиля 5af298441bf89a6df04a2043ebe99bcdfebea13a0fb26219825a528ee89789ef. Старатели выиграли 91 раунд (3,79%) при выбранной эвристике симулятора. Показатель относится к матчам ботов.

## E2. Сервер

Коммит 8668f4e. Vitest c PostgreSQL 17 на изолированном Linux-контейнере — 8/8, включая N01–N07 и ботов. Повтор подтвердил совпадение файлов сервера и выполнил 8/8 за 12,40 с с загрузкой Vitest. Scoped ESLint и pnpm typecheck прошли. Миграция, готовность и остановка по SIGTERM проверены. На Windows воспроизвели ошибки Winsock при множестве коротких соединений. Linux-прогон использовал зависимости и Linux-биндинги точно из закреплённых версий.

## E3. Браузер

Коммит adc0b70. Сборка Vite и проверка 115 WebP по SHA-256 прошли. Playwright на собранном приложении, реальном API, WebSocket и PostgreSQL — 2/2. Сценарий трёх браузерных контекстов прошёл три раунда, повтор матча, приватность, обрыв соединения и выкладку с подтверждением. На первом снимке панель закрывала камеру. После исправления раскладки тот же сценарий прошёл ещё раз за 21,7 с. Получены реальные снимки поля при DPR 1/2/3, в том числе на телефонном размере в эмуляции.

## E4. Проверка поставки

Коммит 344d683. python tools/verify_assets_v2.py package сверил 107 WebP, исходный ZIP и JPG. python tools/verify_assets_v2.py tunnels — 256 краёв, 2 120 соседств, ноль ошибок. Проверка первоначального старта и камер выявила 35 расхождений, что записано в docs/ALPHA_ASSETS.md. Коммит 06d60b9 добавляет восемь отдельных WebP. Строгая проверка board прошла в 32 проверках краёв. Ширина 158–160 px для стандартных и 79–80 px для компактных. Исходные WebP сохранены. Художественная оценка и снимки поля учитываются отдельно.

## E5. Техническая проверка альфы

Коммит a3af8ff. Полный Vitest с PostgreSQL 17 и Node 24 в Linux прошёл 25/25 за 10,43 с с загрузкой Vitest. Windows pnpm check прошёл компилятор, ESLint и 17 тестов. В Windows восемь БД-сценариев были пропущены без TEST_DATABASE_URL и затем вошли в Linux-прогон.

Проверены 20 комнат × 10 активных WebSocket, 720 команд без потерь, p95 ACK 55,6 мс на локальном стенде. Сетевые прогоны на 3/6/10 мест завершили по три раунда, всего 513 команд. Chromium при 10 Мбит/с и RTT 100 мс передал 1 138 359 байт за начальную загрузку, кнопка правил заработала на 568 мс. p95 видимого подтверждения игрового сброса — 143 мс по 20 действиям.

Учебное восстановление прошло на двух выделенных тестовых базах PostgreSQL 17. Копия восстановлена через pg_restore, сервис снова открыл ту же комнату и персональный снимок ревизии 1. Открыты живые партии, физические телефоны, Firefox, LAN/HTTPS, FPS и художественная приёмка.

## Независимая приёмка

Чистый клон a3af8ff. Установка по lockfile с локальным кэшем, типы, линтер, сборка и верификатор 115 WebP прошли. Приложение запущено из исходников чистого клона на изолированном Linux-стенде. Для запуска использованы закреплённые зависимости и совпадающие Linux-биндинги после сбросов скачивания в реестре. Два сценария Playwright прошли за 50,4 с, включая полный матч в трёх браузерных контекстах и повтор. Отдельный Vitest с PostgreSQL прошёл 8/8. Сравнение ZIP с чистым клоном подтвердило 107/107 исходных runtime WebP побайтно. Дальнейшие коммиты после a3af8ff меняют только отчёты и документацию.

Открытое локальное приложение подтверждено примерно через 54 минуты от обновления main, включая разработку и первый полный набор автоматических проверок. Независимая проверка чистого клона и оформление оставшейся приёмки прошли после этого.
